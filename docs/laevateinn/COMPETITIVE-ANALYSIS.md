## AGI Mode: Drop and Go

With Autopilot ON (AGI mode), Daena's full pipeline activates automatically:

1. User drops a query
2. SecurityGate scans it
3. QueryUnderstanding classifies intent + complexity
4. Governance auto-approves (AGI mode, tier 0-2)
5. Laevateinn DCE enriches the query
6. Laevateinn DCS decides: TRIVIAL (fast) or HARD/BRUTAL (full pipeline)
7. For complex queries: AMD debate -> RDE verify -> Gauntlet validate
8. Response delivered with confidence score
9. Background: PKG learns, InteractionLogger records, MetaMonitor tracks

**Zero user intervention required for 95%+ of queries.**
The remaining ~2-5% (critical actions, tier 3+) get human approval -- because governance is the point.
