# Video Skills Router

The orchestrator's index. Given a brief, picks the skill stack. No production
work happens here — only routing decisions.

## Available skill stacks

| Skill | Best for | Duration | Output |
|---|---|---|---|
| `greg-isenberg-explainer` | Educational AI/startup/tech "let me show you" | 15-60s | Vertical 9:16, real B-roll, talking head, snappy captions |
| `scriptwriting-shortform` | Hard news take, hot take, viral hook | 11-90s | Vertical 9:16, JSON schema with hook archetype |
| `video-production` (long-form) | Tutorial 8-20min, deep dive 15-30min | 8-30 min | Landscape 16:9 or vertical, full chapter map |
| `daena_lifestyle` lane | Behind-the-scenes, day-in-life, workspace | 30-60s | Vertical, lo-fi music, Daena casual |
| `masoud_founder` lane | Founder story, build-in-public, lessons | 5-10 min | Voice-only, cinematic, emotional music |
| `higgsfield-marketing` | Product demo, UGC ad, talking-head review | 15-45s | Multi-variant ad pack, paid product focus |
| `voice-direction` | (Always invoked alongside script skill) | n/a | TTS brief + SSML + emotion tags |
| `scene-generation` | (Always invoked when AI B-roll needed) | n/a | Engine-specific prompts (Veo/Sora/Kling/LTX/Wan) |
| `edit-choreography` | (Always invoked) | n/a | Beat map: shots + transitions + captions + grade |
| `video-qa` | (Always invoked AFTER render) | n/a | PASS / WARN / FAIL with sample frames |

## Routing decision tree

```
START
  |
  +--> Brief mentions "explain", "how X works", "playbook", "framework", "let me show you"?
  |    |
  |    +-- YES + topic in AI/startup/tech/no-code -----> greg-isenberg-explainer
  |    +-- NO --> next
  |
  +--> Brief is a NEWS TAKE ("X just shipped", "stat reveals", "company did Y")?
  |    |
  |    +-- YES --> scriptwriting-shortform (archetype = did_you_know|contrarian)
  |    +-- NO --> next
  |
  +--> Duration > 8 minutes?
  |    |
  |    +-- YES --> video-production long-form pipeline
  |    +-- NO --> next
  |
  +--> Brief is "BEHIND THE SCENES", "DAY IN LIFE", "WORKSPACE", "MORNING ROUTINE"?
  |    |
  |    +-- YES --> daena_lifestyle lane
  |    +-- NO --> next
  |
  +--> Brief is a FOUNDER REFLECTION ("lesson I learned", "honest take on building")?
  |    |
  |    +-- YES --> masoud_founder lane
  |    +-- NO --> next
  |
  +--> Brief is a PRODUCT DEMO / AD ("show this product", "convert this link to ad")?
  |    |
  |    +-- YES --> higgsfield-marketing prompt template
  |    +-- NO --> default to scriptwriting-shortform with archetype=mistake
```

## Always-on co-skills (invoked regardless of route)

For ANY video, after the primary script skill produces JSON:

```
1. voice-direction       -> voice brief + SSML + emotion arc + WPM
2. scene-generation      -> per-section visual prompts, engine-tagged
3. edit-choreography     -> beat map: cuts + transitions + captions + grade
4. <renderer>            -> Remotion composition OR LTX/Wan B-roll gen
5. <lipsync if avatar>   -> SadTalker (cheap) OR LatentSync (higher quality)
6. video-qa              -> gates verdict before approval queue
```

## Skill compatibility matrix

| Primary script skill | Voice profile | B-roll source | Avatar | Caption style | QA verdict goal |
|---|---|---|---|---|---|
| greg-isenberg-explainer | AriaNeural conversational | Pexels + screenshots dominant | Daena cutout + SadTalker | Hormozi-pop bottom-third | PASS, asset_relevance >= 0.7 |
| scriptwriting-shortform | AriaNeural sharp-analyst | Mixed: real + Kling/LTX | Daena cutout + SadTalker | Hormozi-pop bottom-third | PASS, scene_diversity >= 5 unique |
| video-production long-form | ElevenLabs Matilda | Heavy real + AI gen | Full talking head + b-roll cuts | Minimal corner | PASS, chapter_completeness 100% |
| daena_lifestyle | AriaNeural warm | Real Daena scene packs | Full Daena, no card | Minimal corner | PASS, lifestyle_aesthetic >= 0.8 |
| higgsfield-marketing | Higgsfield UGC voice | Generated by Higgsfield | UGC actor (not Daena) | Higgsfield template | PASS, product_visible >= 80% frames |

## Anti-routing rules

- Never route a 15-60s short to `video-production` long-form (overkill, slow render)
- Never route a hard news take to `greg-isenberg-explainer` (Greg style is teach-not-tell)
- Never use `daena_lifestyle` for technical explainer (off-brand, lifestyle voice)
- Never use `higgsfield-marketing` for company-news content (it's a product-ad tool)
- If in doubt between `greg-isenberg-explainer` and `scriptwriting-shortform`:
  ask "is the brief asking me to TEACH something the viewer can do, or to REPORT
  something that just happened?" Teach => greg, Report => scriptwriting.

## Brief shape -> skill stack examples

```
"5 viral videos based on AI trends this week"
  -> per-topic decide: news take => scriptwriting, explainer => greg
  -> typical mix: 2-3 greg-style + 2 hard-take = good content portfolio

"Make a TikTok showing how to set up Daena platform"
  -> greg-isenberg-explainer (educational, real screenshots of Daena UI)

"Make a 10-min YouTube video on agentic AI security"
  -> video-production long-form (chapter map: 6 chapters)

"Show off our new product feature in a 30s ad"
  -> higgsfield-marketing (product-link-to-ad pipeline)

"Behind the scenes building MAS-AI today"
  -> daena_lifestyle OR masoud_founder depending on persona

"Anthropic just released Claude 4.7 -- make a hot take"
  -> scriptwriting-shortform archetype=did_you_know
```

## Returning the route

Output a single JSON object:

```json
{
  "primary_skill": "greg-isenberg-explainer",
  "co_skills": ["voice-direction","scene-generation","edit-choreography","video-qa"],
  "renderer": "remotion + offthread-pexels",
  "lipsync": "sadtalker",
  "avatar": "daena_cutout",
  "voice_profile": "ariaNeural-conversational",
  "qa_target_verdict": "PASS",
  "qa_extra_checks": ["asset_relevance","scene_diversity"],
  "rationale": "one sentence explaining why this route"
}
```

This object becomes the contract for the rest of the pipeline.
