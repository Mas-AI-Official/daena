# Content Drafting Skill

Create well-structured written content for any purpose.

## When to Use

- Blog posts and articles
- Email drafts (outreach, follow-up, announcements)
- Business proposals and specs
- Technical documentation
- Social media posts
- Internal communications

## Process

1. **Understand audience**: Who will read this? What do they care about?
2. **Outline first**: Create a structure before writing
3. **Draft**: Write the full content
4. **Review**: Check tone, clarity, accuracy
5. **Suggest edits**: Note areas the user may want to customize

## Content Types

### Blog Post
- Hook/headline -> Problem -> Solution -> Evidence -> CTA
- 800-1500 words typical
- Include subheadings every 2-3 paragraphs

### Email
- Subject line -> Opening -> Body -> CTA -> Sign-off
- Keep under 200 words for outreach
- Personalize the opening

### Proposal
- Executive summary -> Problem -> Solution -> Timeline -> Pricing -> Next steps

### Documentation
- Overview -> Prerequisites -> Steps -> Examples -> Troubleshooting
