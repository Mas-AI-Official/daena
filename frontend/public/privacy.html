6. Data Security

We implement appropriate technical and organizational measures to protect your personal information, including:

  • Encryption in Transit: All data transmitted between your browser and our servers is encrypted using TLS 1.2 or higher.
  • Encryption at Rest: Data stored in our databases and file systems is encrypted at rest using industry-standard AES-256 encryption.
  • Authentication: We use JSON Web Tokens (JWT) for session management and authentication, with secure token rotation.
  • Access Controls: Access to personal data is restricted to authorized personnel on a need-to-know basis.
  • Infrastructure Security: Our hosting on Google Cloud Platform benefits from GCP's enterprise-grade security certifications (SOC 2, ISO 27001).
  • Security Monitoring: We monitor our systems for unauthorized access, anomalies, and security incidents.

Despite our efforts, no method of electronic transmission or storage is 100% secure. We cannot guarantee absolute security. If you discover a security vulnerability, please contact us immediately at daena@mas-ai.co.
