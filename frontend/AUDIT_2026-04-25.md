## Cross-cutting patterns

1. **Silent error swallows are everywhere.** AnalyticsPage, DepartmentsPage, GovernanceApprovalsPage, FilesPage, TasksPage, SkillsPage, ConnectionsPage, MindsPage, ProjectsPage all do `catch { setX([]) }` or `catch { /* graceful */ }` with no user-visible signal. The page LOOKS healthy when backend is down. Per the api.ts interceptor, only certain prefixes are silenced — but pages then *also* silence at the call site. Net effect: backend outages are invisible to the operator. Add inline "backend unreachable — retry" banners at the page level for ALL list-loading endpoints.

2. **Hover-only action buttons hostile to touch.** ProjectsPage edit/delete, PipelinePage advance/lost, FilesPage row menu — all use `opacity-0 group-hover:opacity-100`. Tablet/mobile users see no actions. Make at least one primary action always visible (kebab menu icon).

3. **State-only operations that pretend to hit the backend.** GovernanceAuditPage Archive/Delete/Mark-reviewed are local-only — refresh restores the entries. This is the most dangerous pattern in the codebase. Audit page #1 priority.

4. **Cross-page navigation is frequently broken.** ProjectDetailPage "Open Chat" passes `?project=` that ChatPage ignores. ProjectDetailPage Tasks tab "View" link goes to `/tasks` without filter. MindsPage "N pending proposals" link to `/minds/proposals` (route doesn't exist). DashboardPage SunflowerHive cells aren't clickable. The promise of cross-linked navigation is repeatedly unfulfilled.

5. **Five pages exceed 700 lines.** ConnectionsPage (3,482), SecurityDashboardPage (1,475), ScanPage (1,075), CompanyModePage (974), FounderPage (767). All would benefit from per-tab/per-section component extraction.

6. **Two pages are zombies.** DaenaBotPage (`/daenabot` redirects to `/chat`) and FounderPage (`/founder` redirects to `/settings/governance`) are full implementations behind dead routes. ~1,075 lines of orphan code combined.

7. **Loading states are inconsistent.** Some pages use Shimmer (good), some use Loader2 spinner (mediocre), some use plain text "Loading...". Standardize on Shimmer for any list-loading > 100ms.

8. **Empty states often lack CTAs.** AnalyticsPage charts say "No data yet" with nothing to do. DepartmentsPage falls back to defaults silently. ChatPage on first load is just a blank canvas. Per the protocol: empty states MUST have specific copy + a next-step CTA.

9. **No URL-state for filters.** GovernanceAuditPage filters, TasksPage filter, GovernanceApprovalsPage filter, SkillsPage category — none push to URL. Refresh = lose state. Bookmarkable views are impossible.

10. **Optimistic UI lies on failure.** ConnectionsPage extension permissions optimistically update + toast.error("will revert on refresh") but the local state is NEVER reverted, breaking the toast contract.
